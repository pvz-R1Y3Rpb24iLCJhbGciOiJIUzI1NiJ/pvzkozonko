Панель претензий Ozon и Яндекса

  1. Установите Tampermonkey в браузер, в котором работаете с кабинетами.
  2. Откройте скрипт панели и установите его. Если браузер показывает исходный текст, создайте новый скрипт в Tampermonkey и замените его содержимое этим файлом.
  3. Перезагрузите страницу отдельной претензии в Турбо ПВЗ или ЛК Хабов Яндекса. В Ozon панель появится внизу слева, в Яндексе — справа.
  4. Проверьте полученные данные и нажмите «Сохранить в систему». После сохранения доступны обработка, заметки, график и финансовые события.

История заказа — текстом

Ozon, версия 1.0.5: на уже открытой странице поиска с видимой историей нажмите «Прочитать историю со страницы». Скрипт сохранит текст в браузере по штрихкоду. Вернитесь к претензии и нажмите «Обновить со страницы». Новые вкладки, окна и диагностические файлы не нужны. Если штрихкод явно виден в тексте, чтение также выполняется автоматически после стабилизации страницы.

Версия 1.0.3 подключает найденный API истории Яндекса и выводит события текстом, без вкладок и встроенных страниц. Внутренние ID грузомест запоминаются из загруженного списка заказов выбранного ПВЗ; основной и дополнительный штрихкоды проверяются перед показом истории. Для определения фактического API один раз включите «Диагностика истории → Записать диагностику на 5 минут». В своём кабинете ПВЗ покажите историю нужного грузоместа. Вернитесь к претензии и нажмите «Обновить со страницы». Если события не распознаны, нажмите «Скачать диагностику» и передайте JSON в этот чат. Страницы панель сама не открывает.

Ссылки ПВЗ запоминаются при посещении logistics.market.yandex.ru/common/cabinets. В панели выберите соответствующий кабинет. Родионова (148846298) уже добавлена по подтверждённой ссылке.

Яндекс: претензии, поддержка, почта

Панель работает на /claims/ID/claim, /support/ID и в открытом письме mail.yandex.ru, если в тексте письма есть упоминание Яндекса. Отсутствующие сумму, дату, ПВЗ и статус можно дополнить перед сохранением. Письма и обращения поддержки имеют отдельные устойчивые ID и не перезаписывают карточки претензий.

Ответственность и зарплата

Выбор сотрудника подтверждается вручную. Он сохраняет решение в претензии и не создаёт вычет из зарплаты. График показывает кандидатов для проверки.

Отчёты

Все отрицательные записи из активных вычетов и истории сотрудников доступны в отчёте. Положительные записи являются начислениями. Если маркетплейс не указан в исходной записи, отчёт так и показывает. Суммы не складываются с финансовыми событиями претензий, чтобы не учитывать одно списание дважды.

Диагностика

При ошибке авторизации войдите в кабинет и повторите получение. При изменении маршрутов или API панель покажет ошибку вместо сохранения неполной карточки. Для подписи действий укажите имя оператора: это введённая подпись, а не подтверждённая учётная запись.
